# DIN resistor terminal artwork

## Horizontal top view

- `din-resistor-terminal-top-view.svg`: editable vector illustration with a transparent exterior, `viewBox="0 0 1920 224"`.
- `din-resistor-terminal-top-view.png`: transparent PNG at 3840 × 448 px, rendered from the SVG.

This illustration is reconstructed from the clear horizontal reference in `docs/references/din-resistor-terminal-top-view.png`. It uses the flat fills and fine outlines of the Wirebench module artwork while preserving the supplied terminal's light gray housing, four circular wire openings and square clamps, four orange release units, two oval recesses, central carrier, metal leads, and brown axial resistor with three visible bands.

The SVG contains only vector paths and shapes. Named groups separate the housing, terminal openings, component carrier, resistor leads, and resistor bands for editing. The visible bands are drawn as shown; no resistance value, terminal numbering, or physical dimensions are assigned.

No resistance value, resistor color bands, dimensional specification, or electrical pin assignment is asserted.

The exact manufacturer and complete terminal-block part number have not been confirmed from the cabinet photograph. These illustrations are diagram artwork, not manufacturer CAD.

These files are standalone assets. The terminal block is not yet a connectable module type in Wirebench.
