No resistance value, resistor color bands, dimensional specification, or electrical pin assignment is asserted.

The exact manufacturer and complete terminal-block part number have not been confirmed from the photograph. This is diagram artwork, not manufacturer CAD.

These files are standalone assets. The terminal block is not yet a connectable module type in Wirebench.
